## Selected Projects

- **[Relay Chat](https://github.com/Cfengsu2002/relay-chat)** — Real-time chat with JWT-protected public rooms and PostgreSQL message history. Redis Pub/Sub messaging has been validated across two application instances, with 13 JUnit tests and real HTTP/WebSocket integration checks. Built with Java, Spring Boot, and Docker.

- **[Intern-Hunter](https://github.com/Cfengsu2002/intern-hunter)** — A career-coaching application with AI-assisted resume feedback, internship listings and recommendations, and application tracking. A React/TypeScript interface connects to a FastAPI backend and MongoDB, with support for running AI features through a local Ollama server.

- **[Document Search & Uploads](https://github.com/Cfengsu2002/enterprise-ai-knowledge-assistant)** — Document ingestion, embedding generation, and semantic retrieval, alongside S3 multipart upload workflows. This project explores the storage and retrieval building blocks behind a document knowledge system.

- **[Pathfinding Visualizer](https://github.com/Cfengsu2002/Algorithm-comparer)** — An interactive C++ and SFML project for comparing A* and Dijkstra's algorithms on a grid. It explores how algorithm choices affect pathfinding through a visual interface.
